## 一套片子怎么跑（参考图先行的五段流水线）

**硬规则：先锁形，再出图，最后出片。禁止用 "文字描述保一致" 跳过参考图。**



```
$py = "C:\Users\Administrator\ComfyUI-Installs\ComfyUI\ComfyUI\.venv\Scripts\python.exe"

# ① 建参考图库（人物 / 场景 / 物品），落 06_素材\参考库
& $py "D:\AAA\text\假钦差\短剧\prep_refs.py"          # 拆定妆稿 → 面部 + 全身
& $py "D:\AAA\text\假钦差\短剧\refs.py" all            # 生成禁军/守兵/5 场景/4 道具 + 钦差换装

# ② 用参考图合成分镜（Flux2-Klein 9B 多参考改图）
& $py "D:\AAA\text\假钦差\短剧\shots_flux.py" 01 02 03 # 54 镜，约 20–40 秒/镜，已完成的会自动跳过

# ③ 写 H3 提示词（四段式，已通过技能检查器）
& $py "D:\AAA\text\假钦差\短剧\h3_prompts.py"

# ④ 出视频（首帧 = 该镜分镜图）
& $py "D:\AAA\text\假钦差\短剧\batch.py" reset-videos
& $py "D:\AAA\text\假钦差\短剧\batch.py" videos all    # 54 段，约 4.3 分钟/段

# ⑤ 成片
& $py "D:\AAA\text\假钦差\短剧\make_docs.py"
& $py "D:\AAA\text\假钦差\短剧\assemble.py" 01 02 03
```

阶段闸门：参考图没过 → 不出分镜；分镜没过 → 不出视频。任一处要改，回到上一段重跑，不要在下游打补丁。

前置条件：ComfyUI 在 8188 就绪、Toonflow 在 3000 运行、供应商 `localComfy` 已安装。

`batch.py` 会读 `progress.json` 续跑，已完成的镜头自动跳过；失败镜头记在 `progress.json` 的 `*_error` 字段里。

改过提示词后先跑 `batch.py reset-videos` 清掉旧记录，否则会误判 "已完成"。

## 一致性怎么保（参考图锁形）

**整套素材统一 9:16 竖版，无横版资产。**

人物一律用 "定型稿" 版式（`prep_sheets.py` 自动切分）：9:16 单张画布，上半幅超大面部正面特写，下半幅横向等距正面全身 + 背面全身，纯白无缝底，三视图五官 / 服装 / 褶皱 1:1 统一，腕间不放手表等配饰。

`06_素材\参考库` 结构：



* 定型稿（人物，9:16 整张）：`人物_陈知白_青衫_定型稿`、`人物_陈知白_钦差_定型稿`、`人物_玄甲禁军_定型稿`、`人物_守城兵_定型稿`、`人物_白龙马_定妆`

* 单视图切片（Flux2 实际吃这张）：`*_面部.png`、`*_全身.png`、`*_背面.png`

* 场景板（9:16 竖版）：`场景_贡院`、`场景_青石窄巷`、`场景_乱葬岗`、`场景_清河城门`、`场景_城内小巷`

* 道具板（9:16）：`物品_半枚玉玺`、`物品_蟒袍`、`物品_告示红榜`、`物品_枣红马`

每镜在 `shots_flux.py` 的 `R` 表里声明用哪几张参考图（人物 / 场景 / 物品），Flux2 按参考图重绘，文字只写 "构图 + 光位 + 动作"，不再重复描述长相与服装。



1. 换角色 / 换装 = 只换定型稿，不重写 27 条提示词。

2. 同框多人时，每个角色各自给一张参考图（例如城门镜同时给 "陈知白钦差" 和 "守城兵"），否则会出现服装串味。

3. 参考图里带的文字、水印要在提示词里明确排除；定型稿的纯白底不要带进分镜。

4. 视频以该镜分镜图为首帧，提示词只驱动动作、运镜与声音，不再重生人物。

## 已知问题与下一步

* 768×1344 下 4 步出片约 4.3 分钟 / 5 秒，比 768×1024 慢约 65%；批量排片建议夜里跑。

* 第 4 集起出现新角色（周德海、沈照夜），需要新增定妆图与 `chars` 条目，建议先做定妆再做分镜。

### 复现顺序

1. 按 `_comfyui/ENVIRONMENT.md` 起 ComfyUI（`TQDM_DISABLE=1`，8188）。
2. 把 `06_素材/参考库` 的图放到 ComfyUI `input/`，或直接跑 `shots_flux.py`（它会自己上传）。
3. `python shots_flux.py 01` 出 18 张分镜图 → `python _apply_ep01.py` 回写 `shots.json`。
   - 出图分两档：默认 9b（质量档），`FAST_KEYS` 白名单里的远景/空镜自动走 4b（速度档，约快 30%）。别把 4b 用在告示、画像这类带文字的物证镜。
4. `python batch.py videos 01 --proto`（384×672 原型档，约 18 分钟一集）／ 512×896 审片档 ／ 768×1344 固版（约 78 分钟）。
5. `python make_docs.py 01` → `python assemble.py 01 --proto`。
6. 路径是本机绝对路径（`D:\AAA\...`），换机器先改 `pipeline.py` 的 `ROOT` 与 `shots_flux.py` 的 `COMFY_OUT`。
