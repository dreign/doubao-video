# H3 模型与生成模式

> 本文是面向提示词编排的操作摘要，规则对齐官方 Video Prompt Writing Guide 与 Full-Reference 格式指南；不是官方手册的复制件。产品入口、模型规格和限制可能变化，实际生成前应以用户当前可见的官方界面、文档或 API 返回为准。规则快照日期：2026-11-20。

## 模型边界

| 项目 | H3 规则 |
| --- | --- |
| 输出时长 | MiniMax-H3 标准版：4–15 秒（整数秒）；MiniMax-H3-Max：5–15 秒（不支持 4 秒）。本 skill 分镜切分默认按 5–15 秒规划片段；仅当明确使用标准版且需要 4 秒片段时，下限可放宽到 4 秒。 |
| 帧率 | 24 FPS |
| 声音 | 所有结果带原生双声道声音 |
| 提示词 | 不超过 7000 字符 |
| 文生/全能参考画幅 | 21:9、16:9、4:3、1:1、3:4、9:16；全能参考可选自动 |
| 首尾帧画幅 | 遵循输入图片原始画幅，图片宽高比需在 5:2 到 2:5 内 |
| 768p | 已开放；常规画幅短边 768 像素，极宽/极高画幅总面积约 1M 像素；可升级至 1440p |
| 1440p | 手册推荐；常规画幅短边 1440 像素，极宽/极高画幅总面积约 3.7M 像素 |

不要把清晰度、平台入口或 API 参数硬塞进视频内容提示词。把这些作为参数建议单独提供。

## 输入素材

### 首/尾帧入口

- 输入图片 0、1 或 2 张。
- 0 张等同纯文生（T2VA）。
- 1 张：必须说明是首帧（I2VA）还是尾帧（L2VA）。
- 2 张：明确首帧与尾帧（FL2VA）；H3 补两帧之间的动作、光影和声音，不自动增加切镜。

### 全能参考入口

- 图片不超过 9 张。
- 视频不超过 3 段；单段 2-15 秒，总时长不超过 15 秒。
- 音频不超过 3 段；单段 2-15 秒，总时长不超过 15 秒；音频不能单独输入，必须搭配图片或视频。
- 混合输入不超过 12 个文件。

### 文件格式与单文件大小

- 视频：H.264/AVC、H.265/HEVC；内嵌音频 AAC 或 MP3；单个不超过 50MB。
- 图片：JPG、JPEG、PNG、WEBP、HEIC、HEIF；单个不超过 30MB。
- 音频：WAV、MP3；单个不超过 15MB。
- API 请求体上限 64MB；素材较大时优先使用 URL。

## 模式选择

| 用户资料 | 模式 | 提示词重点 |
| --- | --- | --- |
| 无附件 | T2VA 纯文字生成 | 补全主体外观、空间、动作、风格、声音和镜头层次；无对齐行 |
| 1 张图，作开场 | I2VA 图生视频 | 首帧对齐行；明确图片角色，只写从该帧出发的变化 |
| 1 张图，作结尾 | L2VA 末帧反推 | 末帧对齐行；推断合理开场，让动作、状态、构图、光线逐步收敛到末帧 |
| 2 张关键帧 | FL2VA 首尾帧 | 双帧对齐行；描述两帧之间的连续变化，默认不切镜 |
| 多图/视频/音频 | Ref2VA 多模态参考 | 六段结构；每个素材写清用途及保持的具体维度 |
| 已有视频 + 修改要求 | 视频编辑 | 写明编辑对象、修改项、保持项和声音是否保留 |

## 模式写法

### 对齐行（带图任务固定句式，置于三字段之前，后空一行）

- I2VA：`For the target video, at 0.00 seconds, <Picture 1> from [Shot 1] is fully referenced.`
- FL2VA：`Picture 1 from [Shot 1] aligns to 0.00 seconds; Picture 2 from the actual final [Shot N] aligns to the exact S.SS-second end time.`
- L2VA：`<Picture 1> from the actual final [Shot N] aligns to the exact S.SS-second end time.`

### 纯文字生成（T2VA）

- 省略参考素材段。
- 核心创意必须写具体主体外观、场景细节、事件与风格。
- 多镜头时用大全景、中景、特写建立层次；一镜到底时用连续空间动作链。

### 单图生成（I2VA / L2VA）

- I2VA 写 `@图片1：首帧参考`；L2VA 写 `@图片1：尾帧参考`。
- I2VA 描述从图片状态开始发生什么；L2VA 描述如何自然到达图片状态。
- 明确必须保持的脸、服装、产品结构、构图或画风；首帧已有的静态信息不要文字重述。

### 首尾帧生成（FL2VA）

- 写 `@图片1：首帧参考`、`@图片2：尾帧参考`。
- 不重述两张图中已经清楚的静态信息，集中描述中间连续变化的姿势、物体状态、构图、光线和相机路径。
- 避免 `切镜到`、硬切或多个不连续场景，除非用户明确要求并接受结果偏离首尾帧连续衔接。

### 多模态参考（Ref2VA）

为素材选择准确角色：

- 人物参考：脸、发型、服装轮廓、比例或气质。
- 物体参考：产品结构、材质、颜色或标识位置。
- 场景参考：空间布局、地点特征、光线或天气。
- 构图参考：主体相对位置、景别或画面重心。
- 风格参考：媒介、色彩、颗粒、材质和后期表现；避免误抄无关文字或 Logo。
- 故事板/关键帧：按顺序还原镜头或锁定特定帧。
- 动作参考：动作轨迹、节奏和表演，不默认复刻人物身份。
- 运镜参考：相机路径、速度、稳定度和景别变化。
- 音色参考：说话或唱歌音色；对白/歌词仍需写出。
- 音频复用：完整复用或明确某个时间段/声音轨道的部分复用。
- 节奏/情绪参考：只参考节拍、速度、强弱和情绪，不默认复用原音频。

同一素材承担多个角色时分点写明；只参考其中某一维度时明确排除其他维度。

## 编辑任务

把编辑任务写成"目标 + 修改 + 保持"：

```text
@视频1：视频编辑对象。
修改：把……替换为……；删除……；增加……；把台词改为"……"。
保持：人物身份、原有动作轨迹、镜头运动、构图、时长和未提及声音不变。
```

- 场景替换时补充人物光线、阴影和接触关系如何匹配新背景。
- 角色或物体替换时说明动作轨迹、遮挡、比例和环境光影需要保持。
- 声音修改时写清旧台词、新台词、说话人、音色来源及是否调整表演和口型。
- 高精度多项编辑用项目符号列出，避免把"改什么"和"保留什么"混在长句里。

## 任务类型与保留关系

### 任务类型（summary 前缀，可 `+` 组合，不重复）

- `keyframe completion`：图片作为具体首帧/关键帧/尾帧/编辑关键帧锚点。
- `reference generation`：素材引导身份、场景、风格、动作、相机、分镜、声音、节奏或速度，不直接编辑或续接。
- `video editing`：仅当现有源视频被直接修改；图片之间的编辑或插值不算视频编辑。
- `video continuation`：仅当新内容续接、延伸、恢复或过渡现有源视频。
- `audio reuse`：同一音频信号被完整或部分复制；编辑后的源视频保留可闻原声时也归入此类。
- `audio reference`：信号不被复制，只跟随音色、表达、音乐风格、歌词、音效、节拍、节奏或连续性。

### 保留关系词

- 视觉：`fully_preserved`（完整保留定义性身份与特征）/ `partially_preserved`（保留但改动或省略部分外观、状态、结构、用途）/ `attribute_transfer`（把运动、风格、姿势、构图、效果等属性迁移到不同目标主体）/ `weak_reference`（只跟随大类、氛围、构图族或风格相似性，不暗示身份级保真）。
- 音频：`fully_copy`（整条复用为最终音轨）/ `partially_copy`（只复制选定时间段或轨道，或增删改其他声音）/ `reference`（跟随音色、表达、节拍、风格、台词或质感，不复制信号）/ `weak_reference`（只保留宽泛声音类别或氛围）。
- 取满足需求的最窄关系；只要构图节奏就写 `weak_reference`，不要写 `fully_preserved`。
