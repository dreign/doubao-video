# H3 原创示例

只在需要对应模式的写法参考时读取。不要机械照抄内容；保留结构并替换为用户的真实资料。

> **两层写法说明**：下面的示例是与用户沟通用的**中文分镜草稿**（四段式），不是直接提交给 H3 的最终提示词。交付 H3 前按 `h3-prompt-guide.md` 的官方结构转写：
>
> - 草稿中的"0-3 秒 / 3-6 秒"区间，转写为官方单一切点时刻：`[Shot 1]` 无时间戳；`[Shot 2] At 00:03.000, the camera cuts to …`，切点严格递增。
> - 草稿中的人物台词转成 `<d>[Chinese] …</d>`，并给说话人稳定 ID `(S1)`；身份、语气、动作放标签外。
> - 环境音、动作音效归入 `overall_soundscape`；画内同步音留在主时间轴；观众向配乐写进 `non_diegetic_music`，无配乐写 `N/A`。
> - 多模态参考任务转成六段结构；带图任务先写固定对齐行。
> - 切镜只留给新主体/新空间/新状态/新视角/新时间；距离或角度微调改用运镜（官方词表见 `camera-vocab.md`）。

## 纯文字生成：雨夜悬疑短片

```text
【核心创意】
8 秒，16:9 横版。雨夜的旧城区巷口，一名穿黄色防水外套的年轻快递员发现包裹内飞出一只微弱发光的机械飞蛾，写实悬疑短片，冷蓝路灯与暖黄包裹光形成对比，普通切镜。

【画面过程说明】
0-3 秒：大全景，狭窄湿漉的巷口，快递员骑车急停，雨水从头盔和外套滴落。镜头轻微手持推进。环境音是密集雨声、远处汽车和刹车摩擦声。
3-6 秒：cut 到中近景，他蹲下打开被雨淋湿的纸箱，一只巴掌大小的金属飞蛾展开翅片，暖黄光照亮他的手和惊讶表情。纸板摩擦、金属翅片启动声清楚。
6-8 秒：cut 到面部特写，飞蛾从前景掠过镜头飞向巷子深处；他的视线追随，冷蓝路灯短暂闪烁。镜头快速转向飞蛾离开的方向，在空巷中结束。

【整体要求补充】
真实雨水、皮肤和湿布料质感；机械飞蛾比例稳定，不变成真实昆虫。非叙事性音乐：N/A
```

## 单图首帧：人物情绪转折

```text
【参考素材说明】
@图片1：首帧与人物参考，保持人物的脸、短发、灰色针织衫、窗边坐姿和室内晨光。

【核心创意】
6 秒，遵循 @图片1 画幅。人物从安静凝视窗外到收到好消息后露出克制笑容，写实生活流，一镜到底。

【画面过程说明】
从 @图片1 开始，固定中近景。窗帘被微风轻轻带动，人物先缓慢呼气，桌上的手机震动一次。她低头看向屏幕，眼神从迟疑变得放松，嘴角轻轻上扬，再抬眼看向窗外。镜头只做非常缓慢的推近，不切镜。环境音是清晨远处鸟叫、窗外车流和一次手机震动声。

【整体要求补充】
表情变化细微自然，脸和服装保持一致，不新增人物，不改变房间布局。非叙事性音乐：N/A
```

## 首尾帧：产品形态连续变化

```text
【参考素材说明】
@图片1：首帧参考，锁定银色耳机在黑色桌面的初始位置、构图和冷白轮廓光。
@图片2：尾帧参考，锁定耳机展开后的最终结构、位置和背景构图。

【核心创意】
8 秒，遵循输入图片画幅。银色折叠耳机从 @图片1 的收纳状态连续展开并自然到达 @图片2，一镜到底的高端产品展示。

【画面过程说明】
从 @图片1 开始，镜头缓慢推进。耳罩先轻微抬起，转轴依次解锁，头梁沿真实机械结构平稳展开；冷白轮廓光沿金属边缘移动，桌面倒影随结构变化。耳机完全展开后轻轻旋转到 @图片2 的角度，镜头减速并停在相同构图。只有细小机械咔哒声和桌面接触声，不切镜，不黑屏，不出现额外零件。

【整体要求补充】
产品结构、Logo 位置和金属材质严格稳定；所有运动符合转轴关系。非叙事性音乐：N/A
```

## 多模态参考：动作、人物、场景和节奏融合

```text
【参考素材说明】
@图片1：主角人物参考，保持脸、黑色短发和红色运动夹克。
@图片2：场景与构图参考，使用屋顶球场、铁网和城市夜景，不参考图片中的人物与文字。
@视频1：动作参考，只参考运球、转身和投篮的动作轨迹与速度，不参考人物身份和背景。
@音频1：节奏参考，只参考鼓点强弱和速度，不直接复用原音频。

【核心创意】
12 秒，9:16 竖版。@图片1 的主角在 @图片2 的夜间屋顶球场完成 @视频1 的连续篮球动作，写实时尚运动广告，镜头和剪辑跟随 @音频1 的鼓点卡拍。

【画面过程说明】
0-4 秒：低机位中景，主角快速运球接近镜头，动作轨迹参考 @视频1。镜头后退跟随，球落地声与第一组鼓点同步。
4-8 秒：在重拍处 hard cut 到侧面近景，主角转身过人，红色夹克和铁网被城市灯光勾边。相机短促横移，鞋底摩擦和呼吸声清楚。
8-12 秒：cut 到篮筐后方中近景，主角起跳投篮，动作速度参考 @视频1；篮球穿网时音乐重拍停止半拍，只保留篮网和落地声。镜头停在主角落地后的自信表情。

【整体要求补充】
人物脸、发型和夹克全程一致；球的大小和运动轨迹真实；不复制 @图片2 的原文字或 Logo。
```

## 视频编辑：局部修改并保持其余内容

```text

@图片1：新招牌样式参考，只参考深绿色底板和金色衬线字体，不参考其他画面。

【核心创意】
保持 @视频1 的时长和画幅，对街角咖啡店镜头进行两项局部修改，其余内容稳定不变。

【画面过程说明】
修改 1：把 @视频1 中咖啡店门头原有招牌替换为深绿色底板，金色文字逐字显示为“MOONLIGHT CAFE”，位置、透视、遮挡和镜头运动与原招牌一致，样式参考 @图片1。
修改 2：把门口停放的红色自行车改为奶油白色，保留车架结构、阴影、反射和被路人遮挡的关系。

【整体要求补充】
未提及的人物身份、服装、动作、街道布局、天气、光线、镜头、时长、对白和环境声全部保持 @视频1 不变。不要增加新文字、Logo、车辆或行人。
```
